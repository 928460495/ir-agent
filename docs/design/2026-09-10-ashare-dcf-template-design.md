# A股 DCF 通用模板 — 设计文档

日期：2026-09-10　｜　状态：已确认，进入实现

## 目标

输入一个 A 股代码，产出一份**全公式、可编辑**的三表 + DCF Excel 模型：
历史数据自动写入，可推导的假设自动校准，判断项留白并标注。

## 非目标

- 不支持金融企业（银行/保险/券商）——DCF 不适用，应改用 DDM/超额收益模型
- 不做可比公司/相对估值（已有 china-comps 覆盖）
- 不生成投资建议

## 接口

```bash
python3 ashare_dcf.py <代码> [--years N] [--out DIR] [--no-verify]
```
产物：`<代码>_<简称>_DCF_<日期>.xlsx`，5 页签，历史与预测同表。

## 模块

| 文件 | 职责 |
|---|---|
| `ashare_data.py` | 取数与归一化；不含业务判断 |
| `ashare_calibrate.py` | 从历史推导假设 + beta 回归 |
| `ashare_build.py` | 写全公式工作簿；不知道数据来源 |
| `ashare_verify.py` | formulas 引擎实跑复算；只认工作簿 |
| `ashare_dcf.py` | CLI 编排 |

## 假设：自动 vs 留白

**自动校准（黑字，旁列历史值）**：费用率/税金及附加率、其他收益与投资收益率、
DSO/DIO/DPO、其他流动资产与负债率、折旧率（**OCF 倒推 D&A ÷ 期初固定资产净额**，
不用累计折旧增量——会被处置冲减而低估）、资本开支率（近3年均值并向折旧率衰减）、
实际税率（近3年均值，夹 5%–25%）、少数股东损益占比、期初余额 16 项（精度 1e-8）、
非经营资产（长期股权投资+投资性房地产+其他非流动金融资产）、Beta（5年对上证综指
回归 + Blume 调整）、有息负债利率（财务费用 ÷ 期初有息负债）。

**留白（黄底 + 批注"判断项，必须自行复核"）**：
- 5 年营收增速：默认近 3 年 CAGR 逐年向永续 g 线性衰减
- 5 年毛利率：默认最近一期逐年向 5 年均值回归
- **Bull = Base = Bear**，模板不对情景幅度做任何暗示；旁列历史区间/均值/标准差供拉档参考

## DCF 方法论（沿用已修正版本）

- 终值：Damodaran 一致性 `RR = g / ROIC`，`FCFF_term = EBIT(1+g)(1−t_term)(1−RR)`
- 期中折现开关（默认开）
- 估值基准日滚动（按运行当天自动计算天数）
- 非经营资产加回
- 少数股东双口径开关（账面 / 按利润占比价值法）
- 终值所得税率单列（默认 15%，不假设高新优惠永存）

## 内建验证（生成后自动运行）

列头结构比对 → `None`/`NaN` 显式判失败 → 三情景平衡校验 → DCF 全链路独立复算。
任一失败打印报告并**非零码退出**，不交付坏文件。

## 失败行为

金融企业 / 上市不足 5 年 / 非沪深 A 股代码 / 数据源全挂 → 明确报错并说明原因。
