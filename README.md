# A股 DCF 通用模板

输入一个 A 股代码，产出一份**全公式、可编辑**的三表 + DCF Excel 模型。
历史数据自动写入，可推导的假设自动校准，判断项留白并标黄。

## 用法

```bash
python3 ashare_dcf.py 600183                      # 默认 5 年预测
python3 ashare_dcf.py 002415 --years 7 --out ~/Desktop
python3 ashare_dcf.py 600519 --no-verify          # 跳过验算（不推荐）
```

产物：`<代码>_<简称>_DCF_<日期>.xlsx`，5 个页签，历史与预测在同一张表上。

## 依赖

```bash
pip install akshare openpyxl pandas numpy formulas
```

## 工作簿结构

| 页签 | 内容 |
|---|---|
| `1_假设` | 情景开关、判断项（黄底）、自动校准假设、期初余额、DCF 参数、**股本与融资** |
| `2_利润表` | 历史实际（斜体静态）+ 公式预测 |
| `3_资产负债表` | 同上，含 ★平衡校验 与 NWC |
| `4_现金流量表` | 含循环贷 IF 判断、FCF、FCFF |
| `5_DCF` | WACC、FCFF 现值、正常化终值、EV→每股、反向 DCF、敏感性矩阵 |
| `6_敏感性引擎` | 敏感性计算中间层（每行一个 5 年迷你模型），不需手工编辑 |
| `7_财务比率与杜邦` | 五组比率 + 杜邦三/五因子分解 + 6 张图表，全部活公式 |
| `8_蒙特卡洛` | 模拟参数（可编辑）+ 分布统计 + 龙卷风 + 3 张图（`--mc` 生成）|

**改 `1_假设` 里任何蓝色单元格，全表自动重算。** `B6` 填 1/2/3 切换 Bull/Base/Bear。

## 假设：自动 vs 留白

**自动校准**（黑字，旁列推导规则）：费用率、周转天数、实际税率、少数股东占比、
其他流动资产/负债率、**折旧率（OCF 倒推 D&A ÷ 期初固定资产净额）**、资本开支率
（近3年均值向折旧率衰减）、期初余额 16 项、非经营资产、Beta（5年对上证综指回归 +
Blume 调整）、有息负债利率（财务费用 ÷ 期初有息负债）。

**留白**（黄底 + 批注）：5 年营收增速、5 年毛利率。
默认值仅为保守起点（增速按近3年 CAGR 向永续 g 衰减；毛利率按最近一期向历史均值回归），
**Bull=Base=Bear，模板不对情景幅度做任何暗示**，旁边列出该公司历史区间/均值/标准差供拉档参考。

## 锚定已披露中期

若公司已发布本年中期报告（半年报/一季报/三季报），模板会在「1_假设」页生成
**「三、锚定已披露中期」**小节，**默认开启**：

```
首个预测年营收 = 已披露期实际营收 ÷ 该期占全年营收比重
首个预测年成本 = 已披露期实际成本 + （全年营收 − 已披露营收）×（1 − 剩余期毛利率）
```

- 占比默认取近 4 年同期实际占比的均值（旁注列出逐年值与标准差，通常很稳定）
- 剩余期毛利率默认沿用已披露期毛利率
- **锚定开关置 0 即退回「上年营收 ×(1+增速假设)」的旧逻辑**

锚定逻辑写在「1_假设」的**生效值列**里，不在利润表：

```
生效增速   = IF(锚定=1, 隐含全年营收 ÷ 基期营收 − 1, CHOOSE(情景,...) + Δ)
生效毛利率 = IF(锚定=1, 1 − 隐含全年成本 ÷ 隐含全年营收, CHOOSE(情景,...) + Δ)
```

这样**生效值列永远说真话**——锚定开启时它显示的是实际生效的增速（长电 12.79%），
而不是被绕过的输入值。首年的 Bull/Base/Bear 输入格会**置灰并加旁注**提示不生效。
验证器强制比对「生效值 ↔ 利润表实际使用值」，任何不一致即判失败。

意义：中报出来后，当年营收的一半已是既成事实，再用全年增速假设外推等于丢弃已知信息。
以长电科技 2026 半年报为例，锚定使 2026E 营收从 406.0 亿升至 **438.4 亿（+8.0%）**。

注意：锚定开启时，首个预测年的营收增速与毛利率**判断项不再生效**（该年已被实际数锁定），
敏感性表里的 Δ 也只从第二个预测年起起作用——这是正确行为。

## DCF 方法论

- 终值遵循 Damodaran 一致性：`RR = g / ROIC`，`FCFF_term = EBIT(1+g)(1−t_term)(1−RR)`
- 期中折现开关（默认开）
- 估值基准日自动滚动至运行当天
- 非经营资产加回（长期股权投资+投资性房地产+其他非流动金融资产）
- 少数股东双口径开关（账面 / 按利润占比价值法）
- 终值所得税率单列（默认 15%，不假设税收优惠永存）

## 敏感性分析

`5_DCF` 页共 5 张表，全部为**活公式**，改假设即时重算：

| 表 | 行 | 列 |
|---|---|---|
| 原有 | WACC | 永续 g |
| 模块 A | 营收增速 Δ（对生效路径整体平移） | 永续 g |
| 模块 B | 毛利率 Δ（同上） | 永续 g |
| 模块 C | 营收增速 Δ | 毛利率 Δ |
| 模块 D | WACC | 毛利率 Δ |

**实现方式**：改增速或毛利率会让整条 FCFF 序列重算，无法像 WACC×g 那样一格一公式。
`6_敏感性引擎` 页为此把每个格子展开成**一行完整的 5 年迷你模型**（营收→成本→EBIT→固资→折旧→
资本开支→NWC→FCFF→PV→终值→EV→每股）。可行的前提是 **FCFF 不依赖现金/循环贷 plug**：
EBIT = 营业利润 + 财务费用，财务费用被抵消，因此单行内即可闭合计算。

**轴语义是平移（Δ）而非绝对值**，这样 **Δ=0 / 生效 WACC / 生效 g 的中心格必然复现基准每股价值**——
这是一道内建自检，验证器会强制比对（曾据此抓出 WACC 轴四舍五入偏差 4.6e-05）。

## 已知口径决定（经外部复核后确认）

| 项 | 做法 | 理由 |
|---|---|---|
| 营业利润 | 含「其他经营损益 / 营收」（减值/公允价值变动/资产处置合计，近3年均值） | 不计入会系统性高估营业利润。生益 2022–25 回测每年高估 1.04–1.54 亿 |
| 投资收益 | **不计入 EBIT** | 长期股权投资已在 DCF 桥中作非经营资产加回，同时计入即重复计价 |
| 少数股东占比 | 用**最近年报**，不用 3 年均值 | 结构性比率。生益 2023 −1.3% → 2025 14.3%，均值 6.6% 严重滞后 |
| 营运资本天数 | 用**年报口径**（年末余额 ÷ 全年流量） | 中期「×2 年化」在收入非均匀分布时系统性抬高天数（生益 DPO 126→164），会虚增应付浮存。中期正确年化值写在旁注 |
| EV 滚动至评估日 | 滚动后**扣除期间已实现 FCFF** | 基期年末至评估日的现金流已经发生，不再属于前瞻性索取权 |
| D/(D+E) | 用当前市值权重 | Damodaran 标准做法。该值可编辑；债务权重从 1% 提到 12% 对 WACC 影响约 0.9pp |
| Bull/Bear 初始同值 | **刻意设计** | 模板不对情景幅度做暗示，由使用者自行拉开（见「判断项」一节） |

## 财务比率与杜邦分析（`7_财务比率与杜邦`）

历史与预测同表，**全部为活公式**，改假设即时重算：

| 组 | 指标 |
|---|---|
| 一、盈利能力 | 毛利率、营业利润率、EBIT 利润率、归母净利率、ROE（平均净资产）、ROA、**ROIC（税后）**、对照 WACC |
| 二、营运效率 | DSO / DIO / DPO、**现金转换周期 CCC**、总资产周转率、固定资产周转率 |
| 三、偿债与资本结构 | 资产负债率、净负债/归母权益、有息负债/EBITDA、EBIT 利息保障倍数、权益乘数 |
| 四、现金流质量 | 经营现金流/净利润、自由现金流/营收、资本开支/折旧、FCFF/税后EBIT |
| 五、成长性 | 营收、归母净利、EBIT 增速 |
| 六、杜邦三因子 | 归母净利率 × 总资产周转率 × 权益乘数 |
| 七、杜邦五因子 | 税负比率 × 利息负担 × EBIT利润率 × 总资产周转率 × 权益乘数 × 归母占比 |

**两道恒等式自检**：连乘结果减去直接计算的 ROE 必须为 0（橙底行）。验证器强制比对，
并已用变异测试确认检查有效（注入 0.05 偏差能被捕获）。

ROIC 与 DCF 终值 ROIC 同口径（投入资本 = 营运资本 NWC + 固定资产净额），
所以「价值创造」图里的 ROIC 曲线与 DCF 终值假设直接可比。

### 图表（5 张，引用单元格区域，随模型重算）

1. 营业收入（柱）+ 归母净利润（线，次坐标轴）
2. 盈利能力趋势（毛利率 / 营业利润率 / EBIT利润率 / 归母净利率）
3. **价值创造：ROE / ROIC vs WACC** —— ROIC 持续低于 WACC 即价值毁灭
4. 杜邦：总资产周转率与权益乘数
5. 营运资本周转天数（DSO / DIO / DPO / CCC）

## 蒙特卡洛模拟

```bash
python3 ashare_dcf.py 600183 --mc                 # 建模型 + 蒙特卡洛页（默认参数）
python3 ashare_mc.py <xlsx>                       # 读该文件参数区，重跑，写回同一文件
python3 ashare_mc.py <xlsx> --n 200000 --seed 7    # 临时覆盖路径数/种子
```

**为什么计算在 Python 而不是 Excel**（实测，非偏好）：

| | Excel 原生 | Python |
|---|---|---|
| 1,000 路径 | 56,000 个公式格（当前全簿仅 5,800） | 0.3 ms |
| 10,000 路径 | 560,000 格 | 1.7 ms |
| 1,000,000 路径 | 不可行 | 179 ms |
| 能否被引擎验算 | ❌ 需模拟运算表（已实测会让引擎崩溃）+ `RAND()` 破坏确定性；引擎的 `RANDBETWEEN` 实现还是错的（返回 1.294） | ✅ 固定种子完全可复现 |
| 相关变量 | 需手工展开 Cholesky，极难维护 | ✅ `np.linalg.cholesky` 一行 |

**参数存在 Excel、计算在 Python、结果写回 Excel** —— 改完参数重跑一条命令即可。

### 截尾方式

用**拒绝重抽**而非 `np.clip`。`clip` 会把越界样本堆在边界两点上形成点质量，
恰好扭曲最需要准确的尾部（实测 clip 版有 1.25% 的增速 Δ 堆在 ±2.5σ 两点，改后为 0.0000%）。
截尾边界默认取 ±2.5σ。**税率默认不随机化**，所以其边界仅在手动开启后才起作用。

### 抽样结构（混合）

每条路径先抽一个**路径级平移**（结构性判断），再叠加**逐年扰动**（经营波动）。
方差分解满足 `σ_shift² + σ_year² = σ_历史²`，持续性成分占 25%
（`σ_shift = 0.5σ`、`σ_year = 0.866σ`）。

> 直接把历史**年度**标准差当作 5 年持续平移会严重高估离散度——实测会让每股标准差超过中位数、
> 16% 的抽样撞上截断边界。

### 随机变量

| 变量 | 说明 |
|---|---|
| 营收增速 Δ、毛利率 Δ | 通过 Cholesky 注入历史相关系数（用报表**全部可得年度**计算）。路径平移与逐年扰动**都**带相关性 |
| Beta → Ke → WACC | 比直接抽 WACC 更有经济含义 |
| 永续增长率 g | 逐路径强制 `g ≤ WACC − 间距`，避免终值公式退化 |
| 资本开支率 | 次要变量，纳入龙卷风归因 |
| ~~实际税率~~ | **默认不随机化，固定为报告值**（标准差置 0）。税率由税收优惠资质决定，属政策变量而非经营波动；若要开启，把「实际税率 标准差」填上数即可 |

### 输出

分位数表（P5/P10/P25/P50/P75/P90/P95）、均值、标准差、**P(内在价值 > 现价)**、
**分变量拒绝重抽率**、**均值标准误与 95% 置信区间**、**终值降级路径占比**、**负 EBIT 路径占比**、终值占 EV 中位数；**龙卷风**（各变量取 P10/P90 的每股摆幅）；
3 张图：分布直方图、累积分布、龙卷风。

### 已知局限（务必阅读）

1. **蒙特卡洛围绕的是一条有偏的中心路径。** 默认中心路径是"首年锚定 + 之后机械均值回归"，
   MC 只在其附近加噪声，**不修正中心的偏差**。因此 `P(内在价值 > 现价)` 这个数字主要由中心路径
   决定，而非由不确定性建模决定。实测：生益需要把增速路径整体上移 **+40pp** 才能让该概率达到 7%。
   **正确读法是"在我设定的参数范围内找不到支撑现价的路径"，而不是"市场几乎肯定错了"。**
2. **拒绝重抽会轻微衰减相关系数**：目标 ρ=+0.385，实现值 +0.356（联合尾部被截掉的区域不对称）。
3. **税率（明确期与终值）均不随机化**，固定为报告值。
4. **逐年扰动无自相关**：真实营收增速有序列相关，模型按 iid 处理。
5. **直方图/分位数/龙卷风写入 Excel 的是静态值**，改「1_假设」后需重跑 `ashare_mc.py` 才更新。

### 终值降级规则

当 `ROIC ≤ WACC` 或 `g/ROIC ≥ 1` 时，Gordon 式的 `(1−g/ROIC)` 会失真甚至变负
（实测极端路径 RR 达 109.8、每股 −30.5 元）。这些路径**降级为无增长永续 `TV = NOPAT / WACC`**
——经济上正确：ROIC 等于 WACC 时增长不创造价值。两式在边界处仅差 `(1+g)` 因子（约 3%），切换近似连续。

模拟结果会报告降级路径占比。**这个数字本身有诊断价值**：生益 12.6%、长电 **46.3%**
（长电基准终值 ROIC 10.1% 仅高于 WACC 9.53% 0.6pp，近半路径掉到 WACC 以下）。

### 自检

关闭全部随机（σ 全置 0）后，MC 引擎必须复现确定性模型的每股价值。
该断言在 Python 侧**主动抛错**（已用变异测试确认：注入 5% 偏差会被拦下），
Excel 页上也有一行公式自检。

| 募投资本开支建设期（年） | 3 | 自到账年份起平均投入 |
| 桥接折现年数 | 0 | 0 = 备考口径（视同已完成，卖方惯例） |

### 三张表如何联动

```
募资净额  →  现金流量表 26 行（筹资流入）
          →  资产负债表 25 行（归母权益 +），不走利润表
          →  5_DCF 权益桥「加：增发募资净额（现值）」
偿还债务  →  现金流量表 27/28 行  →  资产负债表 18/22 行（短贷/长贷 −）
募投开支  →  折进现金流量表 14 行（资本开支）→ 压 FCFF、抬固定资产 → 抬后续折旧
增发股数  →  利润表 EPS 自到账年份起摊薄；5_DCF「总股本（含增发）」
```

### 为什么权益桥必须单列一行

DCF 的净负债按**基期**计量，未来募资进来的现金对 EV 完全不可见。
如果只加股本不加现金，就会凭空制造一次**假稀释**。
反过来，把募资现金打进三表**不会**二次抬高 EV——因为 `EBIT = 营业利润 + 财务费用`，
利息收支相抵，FCFF 与现金余额、循环贷全无关系（这也是 `6_敏感性引擎` 能在单行内闭合的原因）。

### 已验证的经济性质

| 检验 | 结果 |
|---|---|

### #12 回购模块

`1_假设` 第七节新增「年度回购金额 / 营收」与「回购均价（元/股）」，默认 0
（A 股回购远不如美股常规）。

**刻意的口径**：回购是**筹资**行为，不改 FCFF 与企业价值，所以

EPS 2.413 → 2.421、**每股内在价值 ¥21.8371 不变**、平衡校验 4.3e-14。

### 「其他非流动资产」不再被抽干

| | 期初 | 修复前 第10年 | 修复后 第10年 |
|---|---|---|---|
| 中免 601888 | 107.2 | **1.6（剩 2%）** | 29.1（剩 27%） |

「其他非流动资产被单向抽干：期初 107.2 → 第 10 年 29.1（剩 27%），按此速度约 4 年后变负」。

## 复审中发现的两处此前未记录的缺陷

**① `ashare_mc.py` 从未跟上折旧/摊销拆分。** 蒙特卡洛的 FCFF 完全漏掉摊销，与确定性模型不一致。
之所以一直没被发现，是因为 9/11 那批模型是**不带 `--mc`** 重生成的，MC 自身的
「关闭随机必须复现确定性模型」断言根本没跑过。已补齐摊销与非现金加回。

**② 我自己的 `ek(31, …)` 撞了回购模块的行号。** 现金流量表第 31 行已被「股份回购」占用，
新增行直接覆盖了它，74 项验算失败才暴露出来。已移到第 33 行。
**教训**：本模板的现金流量表用的是**固定行号**，新增行必须先查占用（当前 6–33 已满）。

# 均胜电子 600699 压力测试后的 3 项加固（2026-09-11 第三轮）

拿并购型、高杠杆、高商誉、少数股东权益占比大的**均胜电子**做检验。模型跑通且验算全过，
但它把几个只有这类公司才会暴露的弱点顶了出来。以下三项**全部是告警，不移动任何估值数字**
（冻结 `cal` 重建逐位比对：生益 `ps=23.384961`、长电 `ps=19.752338`，修复前后完全一致）。

## ① 所有 `_mean` 的截断都要留痕，不只折旧/摊销

上一轮只给折旧率和摊销率加了 clamp 记录，**漏了另外十几个校准项**。
现在 `_mean(..., what=...)` 统一记录到 `_CLAMPS`，随 `cal["clamps"]` 交付，
打印在命令行并写进工作簿第八节。

抓到的真实案例：

| 公司 | 被截断项 | 原值 | 截断为 |
|---|---|---|---|
| 均胜 600699 | 实际所得税率 | **29.75%** | 25%（上限）|
| 中免 601888 | 资本开支投向无形的比重 | **78.49%** | 50%（上限）|
| 中免 601888 | **有息负债利率** | **−13.19%** | 1.5%（下限）|

中免那条负利率尤其说明问题：财务费用净额为负（利息收入 > 利息支出），
倒推出来的"借款利率"是 −13%，模型把它悄悄变成 1.5%。**现在看得见了。**

## ② `sanity()` 两条新规则

- **终值占 EV > 75% 报警**（原阈值 90%，等于不报警）。README 自己写的就是 75%。
- **营收增长而 EBIT 下滑 > 10% 报警**。设 10% 重要性下限，避免轻微下滑（中免 −6%）淹没要命的（均胜 −42%）。

## ③ 资本开支分流比重 > 20% 提示并购口径风险

修复 5 的默认分流按 `申报折旧 : 申报摊销` 推导。对**并购型**公司会过于慷慨 ——
均胜的摊销主体是收购高田/KSS 形成的客户关系与技术，那类资产会自然跑完，
**不由有机资本开支重置**。实测：

| | 终值 ROIC | 每股 |
|---|---|---|
| 分流 43.7%（默认） | 9.71% | ¥15.41 |
| 分流 0%（全进固定资产） | 7.37% | ¥13.70 |

差 **+12%**。生益/长电只有 4% 的分流，看不出来。现在超过 20% 会明确提示。

## 均胜暴露但**尚未修**的两项（会改数字，待确认）

| | 问题 | 影响 |
|---|---|---|
| **Kd 硬编码 `rf + 120bp`** | 均胜实测有息负债利率 **3.95%**，模型用 **2.88%**；债务权重 45.72% | WACC 6.07% → 6.44%，每股 ¥15.41 → **¥13.13（−15%）** |
| **税率上限 25%** | 境外业务占比高的公司实际税率普遍超过 25% | 解除后每股 ¥15.41 → ¥15.59 |

## 这个标的真正的教训：最大的风险不是 bug，是默认假设

均胜毛利率的实际轨迹是**单边上行** `11.63% → 11.96% → 14.46% → 16.22% → 18.30%`，
H1 2026 报 **17.74%**。而模型的默认路径把它推回 6 年均值 **14.51%** ——
等于假设高田整合的转型**会倒回去**。

| 情形 | 每股 |
|---|---|
| 基准（自动校准） | ¥15.41 |
| **毛利率维持 H1 的 17.74%，不均值回归** | **¥44.47** |

**一个黄底判断项造成 2.9 倍的差异。** 模板本来就把增速与毛利率标成「不做外推、请自行拉开」，
但均胜说明：对**处于盈利能力拐点**的公司，自动校准的默认值不能直接用，
比生益/长电危险得多。现在至少 `sanity()` 会喊出「营收增长而 EBIT 下滑 −42%」。

## 模型查不出来的一条

均胜总股本 **15.51 亿**、流通股 **13.96 亿**，差 1.55 亿（10%）。
每股内在价值除以总股本是对的；但**债务权重用的市值 = A 股价 × 总股本**。
若这部分含 H 股或其它折价交易的份额，市值被高估、债务权重被低估、WACC 被低估。
模型没有 A+H / 限售股识别（不足 #7），**需人工确认**。

# 第 3、4 项：债务成本与税率（2026-09-11 第四轮）

前三轮都是告警，这两项**会改数字**。

## 修复前的做法

模型里有**两个利率，互不相通**：

| | 怎么算 | 用在哪 |
|---|---|---|
| `Kd` | **硬编码 `中债10Y + 120bp`** | 只用于 WACC |
| `irate` | 财务费用 ÷ 期初有息负债，3 年均值，截断 [1.5%, 8%] | 只用于利润表的财务费用 |

同一家公司，利润表按 3.95% 付利息，折现率却按 2.88% 算债务成本。
生益/长电债务权重只有 1%/7%，差异被淹没；均胜 **45.72%** 的权重一下就顶出来了。

## ③ Kd 采信实测付息成本（带可用性前置条件）

```
Kd = max(中债10Y + 120bp, 实测付息成本)
实测可用的前置条件：样本年份 有息负债 > 0 且 财务费用 > 0
```

前置条件不能省。中免账上现金远超有息负债，**财务费用净额为负**，
倒推出的"利率"是 **−13.19%** —— 单靠 `max()` 挡住它属于歪打正着，
必须显式判断"净利息收入"这种情形。

四家实测：

| 公司 | 实测付息成本 | 最终 Kd | 说明 |
|---|---|---|---|
| 均胜 600699 | **3.95%** | **3.95%** | 高于下限，采信实测 |
| 生益 600183 | 2.74% | 2.88% | 低于下限，取下限 |
| 长电 600584 | 2.26% | 2.88% | 低于下限，取下限 |
| 中免 601888 | −13.19% | 2.88% | **实测不可用：财务费用净额为负** |

来源字符串 `kd_src` 写进命令行与工作簿第八节，不再只留一句"中债10Y + 120bp 信用利差"。

## ④ 税率上限 25% 改为「不截断但提示」

25% 是法定税率，超过它一定有原因（境外业务、以前年度亏损、递延所得税）——
**那是使用者该判断的事，模型不该替他抹平**。上限放到 45%（只防单年亏损导致有效税率发散），
超过 25% 时明确提示：

```
⚠ 实际所得税率 29.75% 高于 25% 法定税率：常见于境外业务占比高、
  以前年度亏损或递延所得税。已按实际值采用（未截断），请复核是否可持续
```

## 数值影响：只有均胜受影响

| | 修复前 | 修复后 |
|---|---|---|
| 生益 600183 | ¥23.39 | ¥23.38（Kd 仍取下限、税率 10.4% < 25%，**未变**）|
| 长电 600584 | ¥19.76 | ¥19.72（同上，**未变**）|
| **均胜 600699** | **¥15.42** | **¥13.22（−14.3%）** |

均胜同时受两项影响：Kd 2.88% → 3.95%，税率 25% → 29.75%，WACC 6.07% → **6.37%**。
两项都指向【调低估值】，而且都是因为原先的默认值对高杠杆 / 境外业务公司系统性偏乐观。

## 顺带被自己的验证器抓到一次

新加的第八节「债务成本 Kd 来源」与 DCF 参数区的「债务成本 Kd（税前）」**同前缀**，
`ashare_verify._find` 的歧义保护直接报错：

```
KeyError: 「债务成本 Kd」前缀歧义，命中 2 行，请用完整标签
```

标签已改成「Kd（债务成本）来源」。**教训**：往「1_假设」加行时，
标签不能与验证器按前缀查找的既有标签共享前缀。
